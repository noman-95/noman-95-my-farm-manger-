# Farm Manager Premium Clean

This is a clean rebuild from the uploaded project base. The UI is responsive for mobile and desktop.

Run:
flutter clean
flutter pub get
flutter analyze
flutter run -d chrome

Main navigation: Dashboard, Animals, Milk, Finance, More.
Finance types: Income, Expense.
Categories: Milk, Feed, Medicine, Sale, Purchase, Petty Cash, Utility, Salary.
Reports: separate Sales, Purchase, Animals and Finance Excel/PDF exports.
